# Smart Wall Paint Visualizer

## Project Overview

Smart Wall Paint Visualizer is a web-based application that helps users visualize different paint colors on their room walls before painting.

Users can upload a room image, select the wall area, choose a paint color, preview the result, calculate approximate paint requirements and save their projects.

## Live Project

https://smart-wall-paint-visualizer-1-1.onrender.com

## Features

- User registration and login
- Room image upload
- JPG and PNG image support
- Interactive wall selection
- Paint color selection
- Color preview on selected wall
- Undo, redo and reset options
- Paint quantity calculator
- Approximate paint cost calculation
- Save visualization projects
- Responsive web interface

## How It Works

1. User opens the application.
2. User registers or logs into an account.
3. User opens the Visualizer.
4. User uploads a room image.
5. User selects points around the wall.
6. User chooses a paint color.
7. The selected color is displayed on the wall area.
8. User can calculate approximate paint requirements and cost.
9. User can save the project.

## Project Architecture

The application uses a full-stack architecture:

Angular Frontend → Node.js/Express Backend → MongoDB Atlas

The Angular frontend provides the user interface and communicates with the backend through API requests. The backend handles authentication, image uploads and project data. MongoDB Atlas stores application data.

## Project Outcome

The project provides an online solution for experimenting with wall colors using a user's own room image. It demonstrates full-stack web development, database integration, image handling, API communication and cloud deployment.
