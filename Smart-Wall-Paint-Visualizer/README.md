# Smart Wall Paint Visualizer

MEAN-stack college project: Angular 17 + Node/Express + MongoDB/Mongoose.

Features: JWT auth, User/Admin roles, JPG/PNG upload, polygon/brush-style wall selection, color visualizer, undo/redo/reset, before/after, palettes, products, calculator, inspiration, cart-ready UI, offers, testimonials, admin dashboard.

## Run
Backend:
```bash
cd backend
npm install
copy .env.example .env
npm run dev
```
Frontend:
```bash
cd frontend
npm install
npm start
```
Frontend: http://localhost:4200
Backend: http://localhost:5000

Edit `backend/.env` with your MongoDB Atlas URI. Demo admin: admin@smartwall.com / Admin@123
Do not commit `.env`.
